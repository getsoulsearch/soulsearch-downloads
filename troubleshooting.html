Troubleshooting

Things that go wrong, and what's usually going on.

Rekordbox_□x

It synced, but the tracks aren't in Rekordbox.

Rekordbox only re-reads the xml file when it opens. Press Reload on the rekordbox xml list or restart it. If they're still missing, check the files are in the folder, then check the Sync page for where the xml is.

A playlist shows up in Rekordbox but it's empty.

Import it again: right-click the playlist under rekordbox xml, then Import Playlist.

Downloads_□x

Some tracks say not found.

Soulseek didn't have it at your quality when it looked (and SoundCloud / YouTube didn't either, if that's one of your choices). Each source lists its misses under its status on the Sync page: press see which. Try Sync again later, because people come and go on Soulseek. Adding a lower MP3 as another choice in Settings, Quality, finds more.

How much data does this use?

A lot. A big artist is 1 to 2 GB. Don't start one on a phone hotspot.

My internet dropped halfway.

It pauses and picks up where it was when the connection is back. Nothing gets marked as missing because of that.

Back Up or Sync?

Sync takes what you've added since you started using SoulSearch. Back Up goes through everything, including what was there before. Anything already in your library is skipped.

Quality_□x

Can I get FLAC?

Yes. Settings, 6. Quality (or the Downloads card on the Dashboard). Make FLAC your 1st choice, then add MP3 choices after it as a backup, for example MP3 320 then 256. Stop at FLAC and it never takes an MP3. FLAC can only be the 1st choice.

Can I turn off SoundCloud?

Yes. In the same Quality boxes, SoundCloud / YouTube is the last choice in the list. Leave it out (or set that box back to blank) and it's never used. If Soulseek doesn't have a track, it's marked as missing and nothing else is tried.

The app_□x

Windows says it protected my PC.

The app isn't signed yet. Click More info, then Run anyway. If your browser said the file isn't commonly downloaded, choose Keep. A Firewall box about slskd? Allow it on Private networks.

My Mac won't open it.

Drag it into Applications, then right-click it, Open, then Open again. If that fails, System Settings, Privacy & Security, Open Anyway (macOS 15 and newer). If it asks about the Keychain, choose Always Allow. Run it from Applications, not Downloads, or updates won't work.

Spotify says the redirect URI is wrong.

It has to be exactly http://127.0.0.1:8888/callback in your Spotify app's settings. localhost doesn't work. A 403 error instead? The Spotify account that owns the app needs Premium, and your own name and email should be listed under the app's Settings, User Management. The setup guide has the steps.

Does it work on an Intel Mac?

Not yet. Apple Silicon only (M1 and newer).

What does it cost?

The app is free. Crate digging works with any free AI (ChatGPT, Claude, Gemini) through copy and paste, or automatically if you have Claude Code. Spotify needs a free developer app, and Spotify asks for Premium on the account that owns it.
